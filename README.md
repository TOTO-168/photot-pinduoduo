# Photot拼多多

Photot拼多多是一個純前端照片拼貼網頁，支援手機與桌面瀏覽器。照片只會在使用者的瀏覽器中處理，不需要上傳伺服器。

## 功能

- 自動、錯落、橫列與直欄拼圖版型
- 最多 20 張照片
- `1:1`、`4:5`、`9:16`、`16:9` 與自訂尺寸
- 間距、圓角與背景色調整
- 照片拖曳調整與縮放
- 過大照片匯入時自動縮放，降低手機記憶體用量
- PNG / JPG 匯出

## 使用方式

直接開啟 `index.html`，或用任何靜態伺服器啟動：

```bash
python3 -m http.server 5173
```

然後打開 `http://localhost:5173`。

核心回歸檢查可開啟 `http://localhost:5173/?self-test=1`；Console 顯示 `self-check passed` 即為通過。
